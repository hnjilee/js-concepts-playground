# Event Loop

## 이 폴더의 목적

자바스크립트의 싱글 스레드 작동 원리와 브라우저 환경에서의 비동기 처리 과정을 이해하기 위해 작성했다.

## 구성

- **1.flow-of-execution.js**  
  비동기 작업의 실행 흐름을 짚어보며 JS 엔진, Web APIs, 이벤트 루프의 상호작용으로 비동기가 처리됨을 확인한다.

- **2.macro-vs-micro.js**  
  마이크로태스크가 매크로태스크보다 먼저 실행되고, 마이크로태스크는 큐가 빌 때까지 실행된다는 점을 확인한다.

- **3.async-await.js**  
  `await` 키워드가 함수 실행을 중단시키고, 그 하위 코드를 마이크로태스크 큐로 보내는 동작 방식이 `Promise.then()`과 동일함을 확인한다.

## 핵심 포인트

- JS는 싱글 스레드지만, 브라우저의 Web APIs(멀티 스레드) 덕분에 비동기 처리가 가능하다.
- 이벤트 루프는 콜 스택이 비어있는지 지속적으로 감시하며, 대기 중인 콜백을 스택으로 옮기는 역할을 한다.
- 콜 스택이 비면 마이크로태스크를 먼저 전부 실행하고, 그 다음 매크로태스크를 실행한다.
- `async/await`는 `Promise` 기반이다.

## 한 문장 정리

Web APIs는 비동기 작업을 처리하고, 이벤트 루프는 콜 스택이 비었을 때 큐의 작업을 옮겨서 실행하게 만든다.
