# 실행 흐름 이해

## 왜 중요한가?

싱글 스레드 언어인 JS가 어떻게 비동기가 가능한지 이해하지 못하면, 실행 순서를 잘못 예측해서 로직이 의도한 대로 동작하지 않을 수 있다.

## 핵심 구성 요소

- 콜 스택: 실행 컨텍스트(코드 실행에 필요한 정보를 포함한 실행 단위)가 쌓이는 스택 구조
- Web APIs: 브라우저가 제공하는 API 모음으로, 타이머/네트워크/이벤트 등 비동기 작업 처리 영역
- 콜백 큐: 실행 준비가 완료된 콜백들이 대기하는 공간
  - 매크로태스크 큐: `setTimeout` 등
  - 마이크로태스크 큐: `Promise.then`, `async/await` 등
- 이벤트 루프: 콜 스택이 비었는지 확인하고, 비어 있으면 큐에서 콜백을 옮기는 역할

## 실제 동작

- 동기 작업은 콜 스택에서 한 번에 하나씩 실행된다.
- 비동기 작업은 Web API가 대신 수행한 후 콜백을 큐에 등록한다.
- 이벤트 루프가 콜 스택이 비면 콜백을 옮겨 실행한다.
- 마이크로태스크가 매크로태스크보다 먼저 처리되며, 큐가 빌 때까지 처리된다.

## 그래서 어떻게 코딩해야 하나?

- 의도대로 흐름이 진행되도록 실행 순서를 고려해서 작성한다.

## 한 문장 정리

자바스크립트는 싱글 스레드이고, Web API가 비동기 작업을 수행하며, 이벤트 루프가 비동기 작업의 실행 순서를 조정한다.
