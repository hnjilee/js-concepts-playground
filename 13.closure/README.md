# 클로저

## 이 폴더의 목적

클로저가 무엇인지(함수가 선언된 스코프를 기억함)와
클로저로 상태를 유지/은닉하는 대표 패턴을 코드로 확인한다.

## 구성

- **1.concept.js**  
  함수는 선언된 스코프(lexical scope)를 기억하며, 외부 함수가 종료된 후에도 변수에 접근할 수 있다.

- **2.independent-state.js**  
  함수 호출마다 서로 다른 클로저 환경이 생성되어, 독립적인 상태를 유지할 수 있다. (counter1, counter2)

- **3.state-encapsulation.js**  
  클로저로 상태를 캡슐화하고(get/set), 외부에서 직접 접근하지 못하게 할 수 있다. (데이터 은닉)

## 핵심 포인트

- 클로저는 함수가 선언된 스코프를 기억하는 특성이다.
- 클로저를 이용하면 함수가 종료된 후에도 상태를 유지할 수 있다.
- 상태를 직접 노출하지 않고, 접근용 함수(get/set)로만 다루게 만들 수 있다.

## 한 문장 정리

클로저는 함수가 선언된 스코프를 기억해 실행 후에도 상태를 유지/은닉할 수 있게 한다.
