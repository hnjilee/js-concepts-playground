# 웹은 요청과 응답으로 동작한다

## 왜 중요한가?

웹 페이지는 서버의 데이터를 사용해서 화면을 업데이트한다.
브라우저가 서버와 데이터를 주고받는 과정을 이해해야,
요청을 보내고 응답을 받으며 오류 상황에 대처할 수 있다.

## 큰 그림

1. DNS를 통해 도메인 이름을 IP 주소로 변환
2. TCP 연결과 3웨이 핸드셰이크 (안정적인 데이터 전송을 위한 과정)
3. HTTP 요청과 응답 (클라이언트/서버 간 데이터 전송)

## 실제 동작

### 기본 흐름

Browser → Request → Server
Browser ← Response ← Server

### HTTP 요청

- 메서드: GET, POST, PUT/PATCH, DELETE

### HTTP 응답

- 상태 코드: 요청 처리 결과를 나타냄 (200, 404, 500 등)

## 그래서 어떻게 코딩해야 하나?

- 네트워크는 비동기 작업이고,
- 요청은 실패할 수 있다는 점을 인지하며,
- 응답 상태(status)를 확인해야 한다.

## 한 문장 정리

웹은 브라우저가 서버에 요청을 보내고 응답을 받는 구조로 동작한다.
