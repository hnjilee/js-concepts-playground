# Network

## 이 폴더의 목적

브라우저가 서버와 데이터를 주고받는 기본 구조와 CORS의 기본 개념을 정리하고,
자바스크립트에서 네트워크 요청을 보내는 fetch의 동작을 코드를 통해 확인한다.

## 구성

- **1.request-response.md**  
  웹이 요청과 응답 구조로 동작하는 과정

- **2.fetch.js**  
  Fetch API를 사용해 데이터를 요청하고 응답을 처리하는 예시

- **3.cors.md**
  - Same-Origin Policy와 CORS의 개념
  - 브라우저에서의 동작 흐름

## 핵심 포인트

- 웹은 요청(Request)과 응답(Response) 구조로 동작한다.
- 브라우저는 fetch를 통해 서버에 HTTP 요청을 보낼 수 있다.
- 네트워크 요청은 비동기 작업이며 실패할 수 있다.
- 브라우저는 Same-Origin Policy로 다른 origin 응답 접근을 제한한다.
- 서버가 CORS 헤더로 이를 허용하면 브라우저가 응답을 JS에 전달한다.

## 한 문장 정리

웹은 브라우저가 서버에 요청을 보내고 응답을 받는 구조로 동작하며,
Fetch API를 통해 네트워크 요청을 보내고 응답을 처리할 수 있다.
