# Web Storage

## 왜 중요한가?

웹 애플리케이션은 사용자 상태를 유지해야 한다.
관련 데이터를 매번 서버에서 가져오는 것은 비효율적이기 때문에,
브라우저에 저장하는 방식이 필요하다.

## 실제 동작

브라우저는 Web Storage라는 클라이언트 저장소를 제공한다.

- localStorage: 삭제 전까지 유지, 동일 origin
- sessionStorage: 탭 종료 시 삭제, 동일 탭

## 그래서 어떻게 코딩해야 하나?

- 저장 위치에 따라 수명과 범위가 다르다는 점을 인지한다.
- 민감한 데이터는 클라이언트에 저장하지 않는다.

## 한 문장 정리

브라우저는 클라이언트 측 저장소를 제공하여 사용자 데이터를 저장하고 상태를 유지할 수 있다.
