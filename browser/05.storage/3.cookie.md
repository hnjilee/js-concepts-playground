# Cookie

## 정의

브라우저에 저장되고 HTTP 요청마다 서버로 자동 전송되는 데이터

## 사용 이유

HTTP는 stateless이기 때문에 요청마다 사용자 상태를 유지하기 위해

## 기본 동작

서버 응답 → Set-Cookie 헤더 전달 → 브라우저 저장 → 다음 요청 시 자동 전송

## 핵심 특징

- 브라우저 저장
- 같은 origin 요청마다 서버로 자동 전송
- 문자열 key-value 구조

## 웹 스토리지와의 차이

| 구분      | Cookie     | localStorage      |
| --------- | ---------- | ----------------- |
| 서버 전송 | 자동 전송  | 전송 안 됨        |
| 용도      | 인증/세션  | 클라이언트 데이터 |
| 크기      | 작음(~4KB) | 더 큼             |
