# Event

## 이 폴더의 목적

브라우저 이벤트가 어떻게 발생하고,
리스너가 어떻게 실행되는지를 코드로 확인한다.

## 구성

- **1.basic.js**  
  `addEventListener`로 이벤트 리스너를 등록하고, 이벤트 발생 시 콜백이 실행되는 흐름

- **2.event-object.js**  
  `event.target`과 `event.currentTarget`의 차이

- **3.propagation.js**  
  이벤트 전파 단계의 흐름과 `stopPropagation`의 전파를 중단하는 동작

- **4.delegation.js**  
  여러 자식 요소에 리스너를 등록하지 않고 부모에만 등록해 자식에서 발생한 이벤트를 감지하는 방식

- **index.html**  
  코드 실행을 위한 DOM 구조(outer/inner/button, ul/li)

## 핵심 포인트

- 이벤트는 “발생”하고, 리스너는 “등록”한다.
- 이벤트 객체로 정보에 접근한다.
  - target: 실제 이벤트가 발생한 요소
  - currentTarget: 리스너가 등록된 요소
- 이벤트는 캡처링 → 타겟 → 버블링 단계로 전파된다. (기본은 버블링)
- 이벤트 위임은 부모에 리스너를 등록해서 자식의 이벤트를 처리하는 방식이다.

## 한 문장 정리

브라우저 이벤트는 사용자 행동에 반응하기 위한 구조이며,
이벤트 객체와 전파(버블링/캡처링)를 이해하면 위임 패턴으로 효율적으로 처리할 수 있다.
