# 에러 처리

## 이 폴더의 목적

에러가 발생하면 실행 흐름이 중단된다는 점과,
`try/catch`로 에러를 잡아 흐름을 제어할 수 있다는 점을
코드로 확인한다.

## 구성

- **1.problem.js**  
  에러가 처리되지 않으면 실행 흐름이 중단되어 이후 코드가 실행되지 않는다.

- **2.solution.js**  
  `try/catch`로 에러를 잡아 처리하면, 프로그램이 계속 실행될 수 있다.

## 핵심 포인트

- 에러는 기본적으로 실행 흐름을 중단시킨다.
- `try/catch`는 에러 발생 가능 구간을 감싸고, 에러를 처리해 제어를 유지한다.
- `throw`로 에러를 의도적으로 발생시킬 수 있다.

## 한 문장 정리

에러 처리는 실행 흐름을 제어해 프로그램이 예측 가능한 상태를 유지하도록 하는 장치다.
