# Event Loop

## 이 폴더의 목적

자바스크립트가 브라우저 환경에서 어떤 흐름으로 실행되는지 비동기 작업을 중심으로 정리한다.

## 구성

- **1.flow-of-execution.md**
  실행 흐름의 핵심 구성 요소(콜 스택, Web APIs, 콜백 큐, 이벤트 루프)와 비동기 처리의 실제 동작 순서

- **2.flow-of-execution.js**  
  동기 코드와 비동기 코드의 실행 순서

- **3.macro-vs-micro.js**  
  마이크로태스크 우선 원칙, 완전 소진 원칙

- **4.async-await.js**  
  `Promise.then()`과 동일한 `await`의 동작 방식

## 핵심 포인트

- JS는 싱글 스레드지만, 브라우저(멀티 스레드)의 Web APIs 덕분에 비동기 처리가 가능하다.
- 이벤트 루프는 콜 스택이 비어있는지 지속적으로 감시하며, 대기 중인 콜백을 스택으로 옮기는 역할을 한다.
- 콜 스택이 비면 마이크로태스크를 먼저 전부 실행하고, 그 다음 매크로태스크를 실행한다.
- `await` 키워드는 함수 실행을 중단시키고, 그 하위 코드를 마이크로태스크 큐에 예약한다.

## 한 문장 정리

이벤트 루프는 콜 스택으로 콜백을 옮기는 시점을 관리함으로써 비동기 작업의 실행 흐름을 제어한다.
