# 스코프 & 호이스팅

## 이 폴더의 목적

변수의 접근 범위(scope)와 선언이 실행 전에 처리되는 호이스팅 동작을
코드로 확인한다.

## 구성

- **1.scope.js**
  - 변수는 선언된 스코프 내부에서만 접근할 수 있다.
  - 전역 스코프, 블록 스코프, 함수 스코프를 확인한다.

- **2.hoisting.js**
  - `var`는 선언 전에 접근하면 undefined가 출력된다.
  - `let/const`는 초기화 전 접근 시 ReferenceError가 발생한다.

- **3.tdz.js**
  - `let/const`는 호이스팅되지만 초기화 전에는 접근할 수 없다.
  - 이 구간을 TDZ(Temporal Dead Zone)라고 한다.

- **4.function-hoisting.js**
  - 함수 선언문은 선언 전에 호출할 수 있다.
  - 함수 표현식은 변수만 호이스팅되고 함수는 나중에 할당된다.

## 핵심 포인트

- 스코프는 변수에 접근 가능한 범위이다.
- 호이스팅은 변수 선언이 코드 실행 전에 처리되는 동작이다.
- TDZ는 스코프에 존재하지만 초기화 전 접근할 수 없는 구간이다.
- 함수 선언문은 호이스팅되지만, 함수 표현식은 그렇지 않다.

## 한 문장 정리

스코프는 접근 가능한 범위이고, 호이스팅은 선언이 실행 전에 처리되는 동작이다.
