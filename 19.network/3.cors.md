# CORS(Cross-Origin Resource Sharing)

## 핵심 포인트

1. Same-Origin Policy: 다른 origin 응답 접근을 제한하는 브라우저 보안 정책
2. CORS: 서버가 다른 origin 접근을 허용하는 방식
3. Access-Control-Allow-Origin: 이 헤더를 통해 허용함

## 동작 흐름

다른 origin에 요청
→ 응답 도착
→ 브라우저가 CORS 검사 (헤더에 Access-Control-Allow-Origin이 있는지)
→ 허용 시 JS에 응답 전달 / 불허 시 접근 차단

## 존재 이유

다른 origin이 사용자 정보 같은 민감한 데이터를 탈취하는 문제 등을 막기 위해

## Preflight

일부 요청은 더 위험해서 브라우저가 먼저 물어본 후 서버가 허용하면 실제로 요청함

## 정리

브라우저는 Same-Origin Policy 때문에 다른 origin 응답 접근을 제한한다.
서버가 Access-Control-Allow-Origin 헤더로 이를 허용하면, 브라우저가 응답을 JS에 전달한다.
